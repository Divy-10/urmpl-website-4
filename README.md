# URMPL — Website Concept 04 · "Wordmark & Wake"

This is a presentation demo for **United Raw Material Pte. Ltd.** Its design and motion are adapted from a supplied video reference: a screen recording of the "SHIPFLOW" logistics template.
It is **not the production website**. Every page is set to `noindex`, it has never been deployed, and its forms never send anything.
It does not import from, or depend on, `D:\urmpl` or Demos 01–03.

## Run it (Windows PowerShell or cmd, Node.js 20.19+)

```bash
cd D:\urmpl-websites\urmpl-4
npm install
npm run dev          # http://localhost:5176
```

Production build and preview:

```bash
npm run build        # type-check → vite build → dist safety checks
npm run preview      # http://localhost:4176
npm test             # 7 static tests (content, assets, demo safety, routes)
npm run typecheck
```

Optional browser QA sweep. Run it with `npm run preview` open in a second terminal; it needs Playwright (`npm i -D playwright && npx playwright install chromium`):

```bash
node scripts/qa.mjs http://localhost:4176              # 30 routes × 8 widths
node scripts/qa.mjs http://localhost:4176 --shots --full --widths=390,1440
```

```

  components/HubRadial.tsx  Singapore-hub schematic for the Global Network page
  components/forms.tsx      contact + two-step quote forms (demo mode, never send)

  data/content/*.json       verified content copied unchanged from D:\urmpl\src\data\generated
  data/images.json          image manifest (generated by art/encode.mjs)
  styles/                   tokens · base · layout · components · pages

scripts/check-dist.mjs      post-build safety checks
scripts/qa.mjs              responsive / console / overflow / link QA

```

## Notes

- **Content:** URMPL's details come only from the original project's published data. Values marked pending (volume, client counts, emails, leadership, specs) are never shown.
- **Images:** these are original 3D renders made in code (`art/scenes.js`), **not photographs and not AI images**. No AI image generator was available when the demo was built. `docs/IMAGE-PROMPT-PACK.md` has prompts for replacing them; keep the same filenames.
- **Forms:** they validate fully and then say plainly "Demo mode — not sent". They make no network request.
- **Hosting:** this is a single-page app. `vite preview` handles deep links. `dist/404.html` is a copy of `index.html` for static hosts.
